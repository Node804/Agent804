# Shared recommendations

This directory holds optional recommendations used by more than one stack. It does not
declare project requirements or establish a complete stack profile.

- [Style defaults](style-defaults.md): recommended conventions and tools when a project has
  no existing choice, with links to editable starter configurations.

[Rules](../rules.md) state required properties. [Stack profiles](../profiles/README.md) explain
how a particular stack can satisfy them. [Templates](../../templates/) are files to copy and
customize. Once adopted, the project's own configuration is authoritative.
