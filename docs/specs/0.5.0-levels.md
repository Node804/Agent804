# 0.5.0: cumulative assessment levels

Status: Built; kit checks and independent scenario review passed. Real-project trials pending.

Replace eight rungs and foundation/coverage scores with four cumulative core levels:
1 Guided, 2 Controlled, 3 Verified, 4 Sustained. The developer authorized this change
after reviewing this structure in chat. No rule property or module trigger changes.

## Acceptance criteria

1. Level 1 groups former rungs 1–2; Level 2 groups 3–4; Level 3 groups 5–7;
   Level 4 groups 8. Every existing gate remains, with its applicability conditions.
2. A level is earned only when every applicable gate through that level is met.
   Partial or missing gates block advancement. Later strengths cannot compensate.
   Unverified evidence produces an explicitly provisional result, never an unqualified level.
3. Assessments lead with a named level, target, top gaps and next steps; show progress
   toward the next level by named practice. No second foundation or coverage score.
4. Modules retain triggers, grades and Operate O1–O3 scoring, separately from core levels.
5. Setup targets Level 2 before a first feature and reports unexercised gates honestly.
   Project targets use levels plus explicit additional requirements where a prototype
   needs selected protections. No former required protection disappears from a target.
6. Current instructions, links, rule headings, release metadata and evidence claims agree
   on 0.5.0. Historical changelog entries remain historical. Old scores are not converted.
7. The kit check passes. Independent documentation review exercises cumulative blocking,
   partial and unverified evidence, above-target strengths, conditional gates and modules.

## Scope and limits

Documentation and its integrity checks; no application runtime or new scoring service.
No new external references. This is a framework design change requested by the developer,
not an empirically validated maturity model. Reference-project reassessments remain pending.
