# Agent804 0.6.1 public preview

Publication pending. This candidate includes the unpublished [0.6.0 preview](0.6.0.md)
and the setup and portability refinements below. A commit and push do not publish a release.

## Changes since the 0.6.0 candidate

- Onboarding starts with setup or guided adoption. Beginners need not identify missing
  protections or study the framework first; a read-only assessment is optional.
- Setup exercises representative failures through the ordinary project check. Diagnostics
  identify the location, constraint and concrete correction; the correction must pass.
- Relevant setup checks retain structural snapshots for complexity, file/module size,
  duplication and boundary exceptions, with revision, tool, scope and coverage limits.
  Snapshots approve no exceptions, and one snapshot establishes only a baseline.
- Shared instructions require the `spec` workflow even when the user does not name it.
  Resolve it from available skills or the intact kit in the current environment; report
  an unavailable skill before implementation. No local install/cache path is embedded.
- Current-behavior guidance is updated to verified outcomes before review. Evidence summaries
  no longer imply an unrecorded adoption trial or a currently supplied Claude Stop hook.

## Updating and verification

Follow the [0.6.0 migration guidance](0.6.0.md#updating-from-04), preserving project-owned
configuration and reviewing previously copied handlers separately. Projects generated with
an absolute `spec` path should adopt the portable discovery instruction in the current
`templates/AGENTS.md`; updating the kit does not rewrite their instructions.

The repository check establishes consistency, not live-host skill discovery or maintainability
outcomes. Prevention exercises, unfamiliar-maintainer trials and live relocation remain pending.
The earlier 0.6.0 package evidence does not verify these new bytes. Rebuild and verify the
final 0.6.1 archive from its release commit before publishing.
